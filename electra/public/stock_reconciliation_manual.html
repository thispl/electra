1. Overview

Stock Reconciliation is the process of counting and evaluating material/products, periodically and at year-end, in order to:

  • Keep the actual physical stock count and book stock count in sync
  • Value the stock for the preparation of accounting statements
  • Post opening stock into the system
  • Identify discrepancies such as inventory theft or data entry errors

The Stock Reconciliation feature in ERPNext is used to reconcile the stock balance and value with actuals. This ensures accuracy in financial reporting and helps maintain correct inventory levels.

2. Accessing Stock Reconciliation

1
Log into your ERPNext account.
2
Click on the Stock module in the sidebar.
3
Navigate to Tools > Stock Reconciliation.
Tip: You can also search for "Stock Reconciliation" directly in the awesome bar (search bar) at the top of the screen.

3. Creating a New Stock Reconciliation

1
Click on 'New' on the upper right-hand area of the screen.
2
Specify the Posting Date/Time the balance will be effective for. Tick the "Edit Posting Date" box and change the Date and Time as needed.
Note: The posting date determines when the stock balance will reflect in reports. You can make back-dated stock reconciliations as well.

4. Adding Items Manually

On the Items section, click the "Add Row" button to enter each item you need to update the balance. You need to specify the following information:

  • Item Code — Must match the Item Code configured in ERP
  • Warehouse — Must match the Warehouse name configured in ERP
  • Quantity — The actual physical count for that item in the specified warehouse
  • Valuation Rate — The valuation rate for the item (optional; leave blank to keep existing rate)
Tip: Use the Items button to fetch the current stock balance and valuation as of a specific date and time from a selected Warehouse. You can then update the Quantity and Valuation Rate as needed.

5. Uploading Items via CSV File

If there are multiple items, doing a file upload is a more efficient option.

1
To generate the template file, click the "Download" button. A CSV file will be saved to your computer.
2
Open the CSV file and enter the required data: Item Code, Warehouse, Quantity, and Valuation Rate. You can copy-paste from a reference document but make sure you are copying the correct information.
3
Click the "Upload" button and select the CSV file you edited to add the items in your Stock Reconciliation.
Important: Item Code and Warehouse should match exactly with what was configured on ERP. If there is a mismatch, an error will appear when saving the Stock Reconciliation document. Do not edit the headers in the CSV template — they are case-sensitive.

6. Saving & Submitting the Document

1
Click on "Save" to save the Stock Reconciliation document.
2
If there is no error, the document will be saved as Draft. From here, you can click Submit to post the new balance.
Note: After submission, the stock balance will be updated in the system. The Difference Account will be set to 'Stock Adjustment' by default, and the Cost Centre will default to 'Main' — change if needed.

7. Important Reminders

  • To perform an efficient Stock Reconciliation, use the Stock Balance Report first to compare that your "Manual Count" matches with the balance. If there are differences with the manual count, a Stock Reconciliation may be needed.
  • When doing comparison between ERP Count and Manual Stock Count, make sure that you are using the Item Name / Code that are encoded in ERP. This way, unnecessary confusion with "typo", name differences can be avoided.
  • After successfully posting a Stock Reconciliation, always generate a new Stock Balance Report and check if desired changes were applied.
  • Make sure that items that will be zeroed or decreased in quantity are not used in an existing Material Issue transaction from a date after your Stock Reconciliation posting date. If the item's balance in your Stock Reconciliation will be less than the Material Issue quantity, Stock Reconciliation for that item will not be allowed — unless negative inventory is allowed in the organization.

8. Common Errors & Troubleshooting

Error Cause & Solution
Could not find Item "X" Missing Item Code. Usually caused by an error in encoding the Item Code. Verify the exact Item Code from the Item Master.
Could not find Warehouse "X" Missing Warehouse Name. Usually caused by an error in encoding the Warehouse Name. Verify the exact Warehouse name from the Warehouse list.
Item "X" is not a Stock All items in the inventory must be a Stock Item. The checkbox "Maintain Stock" under Item Master must be ticked before you can add inventory to the item. If this error appears, the item is not configured as a Stock Item.
Duplicate Items If there are duplicate Item Codes with the same warehouse on your file upload, this error will appear. Check your CSV template and remove the duplicate entry.
